\section*{Comment Field}\label{comment-field}

En général, tout paquet APRS peut contenir un texte libre (par ex.
message beacon) dans l'Information field, immédiatement après les APRS
Data ou l'extension. Pas de séparateur sauf mention contraire.

Le commentaire peut contenir n'importe quels caractères ASCII
imprimables sauf \texttt{\textbar{}} et \texttt{\textasciitilde{}}
(réservés au TNC channel switching).

Longueur max dépendante du type de rapport --- détails dans la
description de chaque rapport.

Dans certains cas, le champ Comment peut contenir des données APRS
supplémentaires :

\begin{itemize}
\tightlist
\item
  Altitude en texte de commentaire (chapitre 6), ou dans le texte de
  statut Mic-E (chapitre 10).
\item
  Maidenhead Locator en Mic-E status (chapitre 10) ou Status Report
  (chapitre 16).
\item
  Bearing + Number/Range/Quality (\texttt{/BRG/NRQ}), dans les DF
  reports (chapitre 7).
\item
  Area Object Line Widths (chapitre 11).
\item
  Signpost Objects (chapitre 11).
\item
  Weather et Storm Data (chapitre 12).
\item
  Beam Heading \& Power dans les Status Reports (chapitre 16).
\end{itemize}

\section*{Notation Base-91}\label{notation-base-91}

Deux formats APRS utilisent la notation base-91 : lat/long compressées
(chapitre 9) et altitude Mic-E (chapitre 10).

Les données base-91 sont compressées en une courte chaîne de caractères
ASCII imprimables, codes 33--124 décimal (\texttt{!} à
\texttt{\textbar{}}).

Pour calculer la chaîne base-91 d'une valeur, on divise par des
puissances décroissantes de 91 jusqu'à ce que le reste soit \textless{}
91. À chaque étape, ajouter 33 au modulo pour obtenir le code ASCII.

Exemple pour 12345678 :

\begin{verbatim}
12345678 / 91³ = modulo 16, reste 288542
288542   / 91² = modulo 34, reste 6988
6988     / 91¹ = modulo 76, reste 72
\end{verbatim}

Codes ASCII : 49 (=16+33), 67 (=34+33), 109 (=76+33), 105 (=72+33) →
chaîne \texttt{1Cmi}.

\section*{Unités de données APRS}\label{unituxe9s-de-donnuxe9es-aprs}

Pour des raisons historiques, il y a un manque de cohérence dans les
unités : certaines vitesses en knots, d'autres en miles/h ; altitudes en
pieds ou en mètres, etc. Cette spécification décrit les unités
\emph{telles qu'elles sont transmises on-air}. Il incombe aux
applications APRS de les convertir si besoin.

Le datum GPS par défaut est WGS 1984.
